# IS-OOP: Объектно-ориентированное программирование

Репозиторий с лабораторными работами по курсу "Объектно-ориентированное программирование".

## О проекте

Этот репозиторий содержит серию практических работ, демонстрирующих эволюцию подхода 
к проектированию программного обеспечения — от простого ООП-кода до сложной многослойной 
архитектуры с применением всех основных групп паттернов проектирования.

## Что реализовано

**5 полноценных проектов** на C#  
**50+ модульных тестов** с использованием мок-объектов  
**10+ паттернов проектирования** (Builder, Singleton, Prototype, Decorator, Adapter, Composite, Chain of Responsibility, Command и др.)  
**Чистая архитектура** с разделением на слои и инверсией зависимостей  
**Работа с PostgreSQL** без ORM, через прямые SQL-запросы  

## Детальное описание работ

Каждая лабораторная работа находится в отдельной папке и содержит подробный README с 
описанием архитектуры, паттернов и тестовых сценариев.
